## 2026-06-16 本地 Postgres 端口冲突记录

问题：`npm run dev:api` 启动后，Drizzle / pg 报 `role "agent" does not exist`。

根因：本机已有 PostgreSQL 监听 `127.0.0.1:5432`，API 使用 `localhost:5432` 时连到了本机 Postgres，而不是 Docker 容器 `enterprise-agent-postgres`。

固定方案：

- 本项目 Docker Postgres 宿主机端口固定使用 `15432`。
- `.env` / `.env.example` 使用 `DATABASE_URL=postgresql://agent:agent_password@localhost:15432/agent_db`。
- `infra/docker-compose.yml` 使用 `${POSTGRES_PORT:-15432}:5432`。
- 如果再次出现该错误，先看 `docs/local-postgres-port-conflict-runbook.md`，不要重复从 Docker health 或 schema 方向排查。
